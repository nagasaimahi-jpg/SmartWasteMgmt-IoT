# Smart Waste Management App

A mobile-style web app prototype for the project: "Smart Waste Segregation and Collection System using Mobile App Signals and IoT".

## Features included
- Smart waste scan screen
- Nearby bin status dashboard
- Reward and eco points system
- Municipal alert view
- Profile and activity tracking
- Mock smart-bin integration flow

## Tech stack
- HTML
- CSS
- JavaScript
- Vite

## Run locally
1. Install dependencies
   ```bash
   npm install
   ```
2. Start the app
   ```bash
   npm run dev
   ```
3. Open the local URL shown in the terminal.

## App concept
This prototype matches your idea of:
- user scans and identifies waste in the app
- app sends disposal signal to the smart bin
- user earns points for proper segregation
- bin alerts are generated when fill reaches 80%
- municipal staff can track full bins and collection needs

## Project filename
The app is built in the repository root and uses a mobile-first card UI.
